Deep Learning / NLP Text Classifier

Project Overview
This project implements a Deep Learning-based Sentiment Analysis model using Python and TensorFlow. It classifies movie reviews into Positive and Negative sentiments using Natural Language Processing (NLP).

 Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- NLP
- Google Colab

Dataset
IMDb Movie Reviews Dataset containing positive and negative movie reviews.

Implementation
1. Load and preprocess the IMDb dataset.
2. Convert text sequences into numerical representations.
3. Build a multi-layer Neural Network.
4. Apply Dropout and Batch Normalization.
5. Train the model using Early Stopping.
6. Plot training and validation accuracy and loss.
7. Predict sentiment for new text inputs.

 Model Performance
- Test Accuracy: 86.4%
- Test Loss: 0.3281

 Sample Predictions
- "This movie is amazing and wonderful" – Positive
- "This movie is boring and terrible" – Negative

 Expected Outputs
- Model training results
- Accuracy and loss graphs
- Sentiment predictions with confidence scores

 How to Run
1. Download the Jupyter Notebook.
2. Open Google Colab.
3. Upload the `.ipynb` file.
4. Run all code cells sequentially.

 Conclusion
Successfully developed a Deep Learning NLP text classification model to identify positive and negative movie reviews using TensorFlow.
